# PDD 比价

在拼多多商品详情页一键比对历史购买价格的 LSPosed 模块。

## 功能

- **比价**：在商品详情页按商品名称模糊匹配本地历史订单，展示同款商品的历史购买时间、实付价格与购买选项，点记录查看详情。
- **建库**：选择年/月时段，跳转「我的订单」自动翻页采集，屏幕常亮，采集完成或超出时段自动结束。
- **查库**：按名称 / 日期（yyyy-MM）/ 序号搜索，显示建库时间、数据量、首条与末条商品时间。
- **清库**：二次确认后清空本地数据。
- **导出**：导出 xlsx 到手机下载目录。

价格口径：实付价 = 合计拼单价 − 平台优惠。

## 使用

1. 需 Root 环境并安装 LSPosed 框架。
2. 安装本模块后在 LSPosed 中启用，作用域勾选「拼多多」（com.xunmeng.pinduoduo）。
3. 强制停止拼多多并重新打开，屏幕右下角出现「比」字悬浮球即生效。

## 隐私

- 不申请任何系统权限。
- 所有数据仅保存在本地，不上传服务器。
- 只读 hook，不修改应用包、不篡改价格、不自动下单。
